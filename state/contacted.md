# Contacted — do not email anyone on this list again

One address per line. **Grep this file before creating any draft.**

A row lands here **only when a draft was actually sent** (confirmed in Gmail's
sent folder during reconciliation). A draft the user deleted does not belong
here — they rejected that email, so that person stays contactable.

Never delete a row. Removing one allows re-contacting someone already emailed.

Format:

```
<email> | <YYYY-MM-DD sent> | <company> | <role>
```
